# ФОТ PWA — Москва 2 КК

Мобильное веб-приложение для просмотра прогноза ФОТ.
Директора видят только свой магазин, администратор — все.

## Структура проекта

```
fot_pwa/
├── backend/
│   ├── main.py          # FastAPI сервер
│   └── requirements.txt
├── frontend/
│   ├── index.html       # PWA приложение
│   └── static/
│       ├── manifest.json
│       └── sw.js
└── railway.toml         # Конфиг для деплоя
```

## Локальный запуск (для теста)

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```
Открыть: http://localhost:8000

## Деплой на Railway (бесплатно)

1. Зарегистрируйся на https://railway.app
2. Создай новый проект → Deploy from GitHub
3. Загрузи папку fot_pwa в репозиторий GitHub
4. Railway сам запустит приложение
5. В настройках добавь переменную окружения:
   `ADMIN_PIN=твой_пин_администратора`

## Первый вход

- Пин администратора по умолчанию: `admin1234`
  (смени через переменную ADMIN_PIN перед деплоем!)

## Использование

### Администратор
1. Войти с пин-кодом администратора
2. **Загрузка** → загрузить ежедневный файл мотивации .xlsx
3. **Директора** → добавить директора: имя, магазин, пин-код
4. **Сводка** → просмотр прогноза по всем магазинам

### Директор
1. Получить пин-код от администратора
2. Открыть ссылку приложения на телефоне
3. Нажать "Добавить на главный экран" в браузере
4. Ввести пин-код → видит только свой магазин

## Добавление иконок (опционально)
Положи файлы icon-192.png и icon-512.png в frontend/static/
(иконки для PWA на главном экране телефона)

## Безопасность
- Пин-коды хранятся в БД в виде SHA-256 хэша
- Токены сессии истекают через 30 дней
- Директор не может получить данные чужого магазина через API
